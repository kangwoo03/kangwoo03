## 🌱 About

기존 베이스라인과 AI의 도움을 활용해 모델 개선 후보를 탐색하고, 검증 결과와 실제 제출 결과를 비교한 경험을 기록합니다.

- **관심 주제** — 기상 데이터와 태양광 발전량 예측

- **기록하는 내용** — 변경한 점, 선택 근거, 검증의 한계

## ☀️ Featured Project

### [OIBC 2026 · 태양광 발전량 예측](https://github.com/kangwoo03/oibc-2026-solar-forecast)

태양광 발전소 253개소를 두 집합자원으로 구성하고, 집합별 하루전 시간당 발전량을 예측한 개인 프로젝트입니다.

| 살펴볼 내용 | 프로젝트 기록 |
| :--- | :--- |
| 기상 특징 | 인접 시각 예보의 평균·변화량 추가 |
| 모델 개선 | 기존 앙상블의 LightGBM 구성요소 일부 갱신 |
| 모델 선택 | 검증 결과와 대회 제출 결과를 비교 |
| AI 활용 | 개선 후보 탐색과 모델 선택 과정에 도움을 받음 |

> **문서 포트폴리오** · 현재 데이터와 모델 코드는 미공개이며, 저장소만으로 실행하거나 결과를 재현할 수 없습니다. 성과의 근거와 검증 한계는 프로젝트 README에 정리했습니다.
